# Sidebar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Home's sidebar as two always-open sections (Your career, Tools) with Canvas alone at the bottom, and drop the tour's "open Resources" machinery.

**Architecture:** The tour's stops live in `core/first-run.ts`; the `reveal` field and the `resources` anchor go, so My Network is a plain anchor. `web/src/HomeNav.tsx` renders the two headed sections and shows only the Customizations marked ready (Canvas). The window event in `web/src/tour-reveal.ts` and its users are deleted.

**Tech Stack:** TypeScript, React, Vitest, plain CSS (`web/src/home.css`).

**Spec:** `docs/superpowers/specs/2026-11-23-sidebar-design.md`

**Branch:** `feat/sidebar`, cut from `feat/welcome-tour` (#206), because the tour code it changes is only on that branch.

## Global Constraints

- Install and run with **pnpm**.
- Sections, in order: **Your career** (Home, Career History, My Network), **Tools** (Opportunities, Resume Studio, My Docs, Gallery). Headings never fold.
- Canvas: one row at the bottom, above a thin line; toggles the canvas as now.
- Overview, Plugins, Extensions, Tools: not shown; their entries stay in the code.
- Every row uses the app's own 20px line `Icon`; Opportunities uses a new `compass` icon.
- Icons-only sidebar: same rows, same order; headings become a thin divider.
- Commit messages name no other product or repository (AGENTS.md).

## Review Focus

1. **Tour on the network stop**: with the sidebar wide, the outline lands on My Network directly, with nothing opening or closing.
2. **Tour with the sidebar hidden** (phone menu closed): the network and history stops still fall back to the menu button.
3. **Canvas row**: clicking it opens the canvas and marks the row current; closing the canvas elsewhere clears the mark.
4. **Gallery**: its covers still open under it and a cover still opens its role.
5. **Career History page**: the panel still swaps to that page's own list, and Canvas stays at the bottom.

Items 1 and 2 are pinned by the tests in Task 1; 3 to 5 are checked by hand in Task 2.
